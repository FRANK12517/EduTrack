## Live evidence

On October 3, the HTTPS homepage returned 200; /api/health returned 503 with a generic Service unavailable response. Fresh browser navigation and DOM inspection timed out. Closing the old tab also timed out, so recovery was not completed. Captured production console errors repeatedly report TypeError: reverse[dep].indexOf is not a function in buildGraph. No successful School login was observed. On October 4, the bounded homepage recheck timed out. A separate health check at 00:31 UTC returned HTTP 503 with the same generic response.

The scanner uses ordinary object keys for component names. The branch now uses null-prototype maps and tests constructor, toString, __proto__, and hasOwnProperty without collisions. This corrects the observed exception; its contribution to the browser timeout remains unproven. No production data or authentication rules were changed for this fix.

Production configuration validation and relational initialization remain separate possible failure points. Hosting logs/configuration and registered test-account assignments were not accessible through an authenticated hosting connection. The exact cause of the 503 is unconfirmed.
